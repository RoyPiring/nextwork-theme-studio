# Install on Chrome

## Load it

1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this folder: the one containing `manifest.json`
5. Open nextwork.ai

Pin it: click the puzzle-piece in the toolbar, then the pin next to
**Pineapple NextWork Theme Studio Mod**.

`Alt+Shift+D` toggles the theme. Rebind at `chrome://extensions/shortcuts`.

## Updating

Replace this folder's contents, then click the **reload** arrow on the
extension's card. Tabs already open keep the old version until you refresh them.

The version on the card is the quickest way to tell whether a reload took.

## Notes

- Chrome keeps unpacked extensions across restarts, but shows a "Disable
  developer mode extensions" prompt on some launches. Dismissing it is fine.
- Your themes live in this browser profile only. Use **Export theme** in the
  editor to move one to another browser.
