# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

## What that means here

- Critique the code, not the person. "This breaks on Firefox" is useful;
  "this is amateur work" is not.
- Say why. A rejected idea with a reason teaches something; a rejected idea
  without one just stings.
- Take feedback the same way you would want it given.
- No harassment, personal attacks, or unwelcome attention. Ever.

## Scope

Issues, pull requests, discussions, and any other space representing this
project.

## Enforcement

Report anything that needs attention by opening an issue, or privately through
GitHub if you would rather not do it publicly. Reports are handled discreetly.

Consequences scale with the behaviour: a note, a warning, or a block.
Maintainers make the final call.

This is adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
v2.1, shortened for a small project.
