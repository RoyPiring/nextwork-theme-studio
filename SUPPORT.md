## Before opening an issue

Two things solve most reports:

**Check the version.** Open your browser's extensions page and compare what it
says against [the latest release](https://github.com/RoyPiring/nextwork-theme-studio/releases/latest).
An unpacked copy does not update itself, so a fixed bug can still be sitting on
your machine.

**Reload the page.** The theme is applied by a content script, and a tab opened
before the extension was reloaded is still running the old one.

## What to include for anything visual

This project is about how a page looks, so a description of a colour is rarely
enough to act on. A useful report has:

- a screenshot
- the theme name
- whether **Wallpaper** was on
- the page you were on

The single most useful thing is a screenshot showing the problem next to
something that looks right.

## What this project is not

It is an unofficial extension that recolours a website. It is not made by
NextWork, is not connected to them, and cannot help with your account, your
projects, or anything the site itself does. For those, contact NextWork.

## What to expect

One person maintains this in their own time. Issues are read, but there is no
response time to promise and no guarantee that a request will be built. A pull
request will always get further than a request, and
[CONTRIBUTING.md](CONTRIBUTING.md) covers how to make one.
