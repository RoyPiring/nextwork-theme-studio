Borrowed from Anno: the tier is not a score, it is what the place is. A camp has a tent and a fire. A village has a road. A town has districts by tag. A city has a skyline that says what you do for a living.

THE TWO SURFACES

  • World lives on the portfolio page. It is the whole account: every project, every building, the avatar wandering its own roads. This is the thing you screenshot and put in a job application.
  • Build lives on a project page. One construction site for the project you are in, rising as steps complete, with the time you have put in. It gives a long project a shape while you are inside it.

WHAT THE EXTENSION CAN ACTUALLY READ

Everything here runs inside the existing extension's rules: no network, no account, nothing leaves the machine. The world is built from three things the page already shows:

  • The project's tag and title — read from the page heading, the way the theme already reads it.
  • Which steps are ticked — the same checkboxes the page draws.
  • Time on the page while the tab is in front — the focus timer already measures this.

State is stored where the themes are stored, so it survives reloads and never syncs anywhere. The art is drawn from tiny sprites in code — no image files, nothing downloaded.

STYLE

Top-down, 16px tiles scaled ×2, a Game Boy Advance palette. The Pokémon overworld for the map, MapleStory for the character and the way buildings pop in, Clash of Clans for the plot-and-place layout. 2D on purpose: it draws in a side panel at 60fps on a laptop, and a pixel sprite is a thing one person can make in an afternoon.

OPEN QUESTIONS FOR THE TEAM

Does NextWork want completion to be readable from the page, or would they rather hand the extension a small signal? Both work; the second is cleaner.
Is the world per-account on their side one day, or does it stay in the browser? Staying in the browser is honest and free; moving it makes it portable.
Who draws the second hundred sprites? This demo has a dozen. A city needs a tileset, and that is a designer's week, not an engineer's.
